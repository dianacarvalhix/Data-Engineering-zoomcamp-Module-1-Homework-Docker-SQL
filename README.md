# Data Engineering Zoomcamp

This repository contains my work and notes while following the Data Engineering Zoomcamp course by DataTalksClub.

The goal of this repository is to document my learning journey through the course by:
- following the lessons and workshops
- completing the hands-on exercises
- developing the homework assignments
- practicing data engineering tools and concepts

## Course Topics

Throughout the course, I will work with topics such as:
- Docker and containerization
- Workflow orchestration with Kestra
- SQL and PostgreSQL
- Google Cloud Platform (GCP)
- BigQuery
- Data ingestion pipelines
- ETL/ELT workflows
- Data warehousing
- Analytics engineering
- Batch and streaming data processing
